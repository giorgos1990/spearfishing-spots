# Spearfishing Spots

## [⬇ Download this app (Android)](https://github.com/giorgos1990/spearfishing-spots/releases/latest/download/SpearfishingSpots.apk)

Android app for spearfishing in Cyprus: save your spots, navigate back to them, log your catches and see the sea forecast for every coastal village.

### Install on your phone
1. Tap **Download this app** above (you must be signed in to GitHub).
2. Open the downloaded `SpearfishingSpots.apk`.
3. If Android asks, allow installing apps from this source, then tap **Install**.
4. Open the app and allow **Location (Precise)** and **Notifications**.

Needs Android 7.0 or newer.
